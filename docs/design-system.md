# Design System — The Bastards Agency

## Mod: DARK MODE

## Culori globale (Elementor Global Colors)

| Variabilă | Hex | Utilizare |
|---|---|---|
| `--theme-accent` | `#FF6A00` | Accent principal, CTA |
| `--theme-accent-alt` | `#FF7F1A` | Hover accent |
| `--strongest-text` | `#1a1a1a` | Text foarte întunecat |
| `--strong-text` | `#3c3c3c` | Text principal light mode |
| `--medium-text` | `#525252` | Text secundar |
| `--subtle-text` | `#777777` | Text terțiar / placeholder |
| `--subtle-background` | `#eeeeee` | Fundal subtil light |
| `--lighter-background` | `#fcfcfc` | Fundal mai deschis |
| `--white` | `#ffffff` | Text pe fundal dark |
| `--dark-orange-button` | `#FF6A00` | Butoane portocalii |
| `--dark-background-1` | `#0E0E0E` | Fundal principal dark |

### Reguli dark mode
- Fundal principal: `#0E0E0E`
- Text pe fundal dark: `#ffffff`
- Accent: `#FF6A00`

## Tipografie

| Font | Weights | Utilizare |
|---|---|---|
| **Space Grotesk** | 300, 400, 500, 600, 700 | Headings |
| **Inter** | 100–900, normal + italic | Body text |
| **Krona One** | 400 | Accent / Logo |
| **IBM Plex Sans** | 400 | Alternativ |
| **Montserrat** | 400, 700 | UI |
| **Open Sans** | 400 | UI |

### Reguli tipografie
- Headings → Space Grotesk 600–700
- Body text → Inter 400
- Butoane → Space Grotesk 500–600

### Iconițe
- Font Awesome 5
- Dashicons
- Eicons

## Border & Radius

| Proprietate | Valoare |

| Border Width | 1px (toate laturile) |
| Border Radius | 10px (toate colțurile) |
| Border Color | variabil (din global colors) |
